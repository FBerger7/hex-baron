# Hex Baron 🎩🎲

**Hex Baron** (*The Smoke-Filled Room*) to single-playerowy roguelike typu *hex-builder / synergy engine-builder* tworzony w **Godot 4**. 

Łączy taktyczne budowanie planszy i rzuty kośćmi rodem z *Catana* z wykręconymi synergiami i modyfikatorami reguł w stylu *Balatro* oraz *Terracards*, całość ubierając w gęsty klimat zadymionego gabinetu cieni i satyry politycznej.

### Główne filary gry:
- **Zadymiony Gabinet Cieni:** Rozgrywka na jednym ekranie mahoniowego stołu sztabowego wśród teczek `TOP SECRET` i dymiących cygar.
- **5 Sektorów Kafelków:** *Gospodarka, Przemysł, Media, Społeczeństwo, Służby* – każdy z własnymi regułami sąsiedztwa i przekazywania impulsów.
- **System Anty-Frustracyjny ("Pęczniejące Obietnice"):** Kafelki nietrafione rzutem kości kumulują kapitał z odsetkami składanymi (+25% za każdy pominięty rzut), zamieniając chwilowego pecha w wielką eksplozję punktów przy kolejnej aktywacji.
- **Gabinet Polityków (Jokery):** Parodie międzynarodowych ikon polityki, które łamią zasady ekonomii, manipulują kośćmi i wykorzystują **Wskaźnik Skandalu (Heat)**.
